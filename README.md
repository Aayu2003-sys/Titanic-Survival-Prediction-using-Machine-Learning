# Titanic Survival Prediction using Machine Learning

## Project Overview
This project analyzes the Titanic dataset to understand the factors that influenced passenger survival. Using data analysis and machine learning techniques, the model predicts whether a passenger survived based on features such as age, gender, passenger class, and fare.

The project demonstrates the complete data science workflow including data preprocessing, exploratory data analysis, model building, and evaluation.

## Objectives
- Analyze the Titanic dataset
- Identify factors affecting passenger survival
- Perform data preprocessing and feature engineering
- Build machine learning models for prediction
- Evaluate model performance

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The dataset used in this project is the **Titanic Dataset**, which contains information about passengers such as:
- Passenger Class (Pclass)
- Name
- Sex
- Age
- Fare
- Number of siblings/spouses aboard (SibSp)
- Number of parents/children aboard (Parch)
- Survival status

## Project Workflow
1. Data Collection  
2. Data Cleaning and Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Feature Selection  
5. Model Training  
6. Model Evaluation  
7. Survival Prediction  

## Process Flow
Dataset → Data Cleaning → Exploratory Data Analysis → Feature Engineering → Model Training → Model Evaluation → Prediction

## Results
The machine learning model analyzes passenger attributes and predicts survival probability. The project highlights how factors like **gender, passenger class, and age** significantly influenced survival chances.
